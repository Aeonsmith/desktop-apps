# ⚡ Rigour Mortis Skate Singularity Tycoon

An avant-garde, cubist interactive simulation exploring the entropic collapse of dogmatic structures, kinetic paradox economies, and macroeconomic identity arbitrage.

---

## 🌌 Overview & Concept

The simulation merges Picasso-inspired cubist planar geometry with an entropic tycoon game loop:
- **Kinetic Paradox Generation**: Deploying multi-faceted roller skaters into the physical vacuum yields paradoxical kinetic entropy ($\Psi$).
- **Council of Ricks Structural Dissolution**: A 60-node Citadel matrix visualizes the systematic de-coherence and dissolution of rigid authority structures into forgotten myth.
- **Micro-Scale Insect Maintenance**: Entropy allocation preserves Darwinian evolutionary viability against catastrophic dead-ends.
- **Paradoxical Identity Arbitrage**: Exploits superpositioned identity ambiguities to exponentially double the global thermodynamic yield.

---

## 🛠️ Architecture & Features

### 1. Real-Time Telemetry Dashboard
- **Entropy Waveform Oscilloscope**: Sub-second telemetry plotting $\Psi$ accrual vs. zero-static baseline.
- **Citadel Dissolution Matrix**: 60 dynamic cell nodes transitioning across 4 distinct phases:
  - *Phase I*: Central Citadel De-coherence
  - *Phase II*: Portal Residue Evaporation
  - *Phase III*: Memory Amnesia & Myth Transition
  - *Phase IV*: Complete Erasure
- **Singularity Telemetry**: Live readouts for Governor Static Decay, Faith-to-Physics coupling, and Global Arbitrage Multipliers.

### 2. Temporal Resolution Controller
- **`0x (PAUSE)`**: Halts kinetic physics and thermodynamic decay while preserving real-time UI interactivity.
- **`0.25x`**: High-resolution Planck-scale slow motion.
- **`1x`**: Nominal simulation baseline.
- **`2x` / `5x`**: Accelerated entropic dissipation.
- **`10x WARP`**: Hyper-speed conceptual annihilation.

### 3. Visual Feedback & Shaders
- **Entropic HUD Banner**: Alerts across the screen on milestone achievements.
- **Dynamic Polygonal Shockwaves**: Concentric polygon ripples radiating on upgrades and canvas clicks.
- **Screen Shake & Flash**: Chromatic aberration bursts on critical state shifts.
- **Interactive Harvesting**: Clicking the canvas harvests localized kinetic entropy shards.

### 4. Persistent Event Log
- Sub-second formatted timestamps `[HH:MM:SS.m]`.
- Category filtering (`ALL`, `MILESTONE`, `COLLAPSE`).
- Real-time event tracking and memory buffer retention.

### 5. State Serialization (Save & Load)
- **Export (`💾 Export JSON`)**: Serializes all thermodynamic state variables, upgrade costs, milestone progression, individual skater polygon geometry/vectors, and the full event log into an `entropic_state_<timestamp>.json` bundle.
- **Import (`📂 Load JSON`)**: Restores complete game state, re-instantiates skater entities with preserved geometry/spin vectors, and rebuilds dashboard telemetry.
